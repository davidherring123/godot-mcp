# godot-mcp 0.2.0

This release expands live resource editing and game automation, improves editor
diagnostics, and adds regression coverage for resource safety and runtime deadlines.

## New capabilities

- **Resource editing:** inline meshes/materials/shapes; typed Resource arrays with
  saved references, inline values, nulls, and custom script types; nested indexed
  properties; and inspection of embedded subresources.
- **Editor tools:** `node_overrides`, guarded `scene_reload`, bounded save diffs,
  `filesystem_scan` with UID verification, and graphical `editor_capture`.
- **Runtime automation:** `runtime_input`, `runtime_wait`, incremental
  `runtime_logs`, capture waits/post-render synchronization, and status freshness
  metadata.
- **Input Map and batches:** built-in action filtering, multi-name inspection,
  stored-event results, and qualified action aliases for resource, Input Map,
  and project-settings batches.
- Scene lists exclude addon scenes by default; Control layout edits,
  ShaderMaterial parameter assignment, packed-array diagnostics, and structured
  MCP errors are improved.

## Reliability and packaging

- Resource-path reassignment and incomplete graph readbacks fail safely rather
  than risking file overwrites or silently losing data. Resource file actions
  reject lexical paths outside the project.
- UID registration survives trailing no-op batch operations. Indexed result
  readbacks are corrected, and save diagnostics avoid claiming an unchanged file
  proves the editor buffer was saved.
- Runtime deadlines include queue time, reserve a response margin for partial
  input reports, and bound stalled capture barriers. Older runner sessions get
  a clear restart instruction for the new features.
- Temporary Windows request-file locks are retried rather than reported as
  malformed JSON.
- UTF-8 log cursors preserve split characters and valid text around malformed bytes.
- Addon `.uid` sidecars are no longer shipped. Godot generates them in the target
  project; embedded resource/scene UIDs remain supported.
- Versions and tags are numeric (`0.2.0`, without `v`), with matching addon/host
  stamping. Go line endings are normalized for Windows formatting checks.
- Tests now have a two-minute package timeout and a three-minute CI test-step
  limit. Agent instructions prohibit inflating timeout limits without approval.

## Install / upgrade

Download **`godot-mcp-addon-0.2.0.zip`** for all supported platforms, or choose a
platform-specific archive. SHA-256 checksums are provided in `SHA256SUMS`.
GitHub's automatic source archives do not contain the bundled host binaries.

Disable the plugin, replace the old `addons/godot_mcp` directory with the archive's
directory, and re-enable it. Replacing instead of overlaying removes old shipped
sidecars. Repair client integrations from the panel if needed. Stop and restart
existing runtime sessions to use the new automation features.

## Known limits

Typed Resource arrays support whole-array replacement; nested arrays and
`ref`/`cycle` reconstruction are not supported. Incomplete resource inspection
graphs cannot be submitted unchanged as writes. Physical input can interleave
with synthetic runtime input, and a fully stalled game cannot return deadline
reports. Path containment does not resolve symlinks. Custom Resource constructors
and setters can run during dry runs; rollback remains best-effort and per-domain.
Captures require graphical rendering. Host binaries remain unsigned/unnotarized.
